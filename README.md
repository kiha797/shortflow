# 쇼트플로우 · Render 배포 버전

PC에 프로그램을 설치하지 않고 브라우저에서 AI 쇼츠를 제작하는 소규모 시험용 버전입니다. Render 배포·실제 API 결제·YouTube 업로드는 아직 실행하지 않았습니다.

## 가장 간단한 시작 순서

1. GitHub에 새 저장소(예: shortflow)를 만드세요. 비공개 저장소도 Render 계정에 접근 권한을 연결하면 사용할 수 있습니다.
2. 이 압축 파일을 풀고 **Dockerfile, render.yaml, server.mjs, core.mjs, package.json, public 폴더**가 저장소 최상위에 오도록 업로드하세요. ZIP 자체만 올리는 방식은 아닙니다.
3. Render 대시보드에서 **New → Blueprint**를 누르고 해당 GitHub 저장소를 연결하세요. 설정 파일은 `render.yaml`, 플랜은 Free입니다.
4. 배포 화면에서 아래 두 항목을 입력하세요.
   - `ACCESS_PASSWORD`: 이 사이트에 접속할 나만의 비밀번호. **12자 이상**.
   - `GEMINI_API_KEY`: Google AI Studio에서 발급한 API 키. 결제 및 Veo 사용 권한 필요.
5. 배포가 완료되면 Render에서 제공하는 주소를 여세요. 로그인 창의 아이디는 **admin**, 비밀번호는 위 ACCESS_PASSWORD입니다.
6. 사이트의 채널·API 설정에서 채널 범위와 예상 단가 확인 → 실제 제작 → 영상 만들기.
7. 완료되면 **완성 영상 다운로드**. 처음에는 내려받은 파일을 YouTube Studio에서 직접 업로드하는 방식을 권장합니다.

Node.js, FFmpeg, FFprobe, 한글 자막 글꼴은 배포 중 서버에 자동 설치됩니다. PC에는 설치할 것이 없습니다. Render 무료 서버에서 첫 실제 제작 속도 및 메모리 사용은 확인이 필요합니다.

## 비용 설정

기본 영상 모델은 `veo-3.1-lite-generate-preview`, 720p, 원본 8초 × 4장면입니다.

배포 파일의 `VIDEO_SECOND_KRW=70`은 **초당 $0.05 × 가정 환율 1,400원**이라는 예산 계산 예시입니다. 실제 요금/환율에 맞춰 Render의 Environment에서 바꾸세요. `OTHER_ESTIMATE_KRW=100`은 1편의 대본·음성 비용 여유분 예시이며 청구 단가를 보장하지 않습니다. 기본 표시 예상 비용은 2,340원입니다. 재생성·세금·해외결제 수수료는 별도입니다.

계산값은 결제 상한이 아닙니다. Google Cloud 예산 알림도 자동 결제 중단을 보장하지 않습니다. 실제 생성에 들어가기 전 모델 단가와 결제 설정을 확인하세요.

## 무료 Render의 저장 제한

- 접속이 없으면 서버가 잠들 수 있으며 첫 접속 때 대기 시간이 있습니다.
- 재배포·재시작·절전 후 영상 파일과 제작 이력, 사이트 안에서 바꾼 설정이 사라질 수 있습니다.
- 제작 중에는 페이지를 열어 두고, 완성 즉시 파일을 내려받으세요. 제작 도중 서버가 재시작되면 원격 Veo 작업은 계속될 수 있지만 이 앱에서는 자동 재결제하지 않습니다.
- 브라우저 체험 이력은 해당 브라우저에만 남습니다. 실제 제작 이력은 임시 서버 디스크에 저장됩니다. 서버 초기화 뒤에는 중복 주제 검사에 이전 이력이 반영되지 않습니다.
- 장기간 보관·안정적인 매일 자동 제작이 필요하면 별도 영구 저장소와 안정적인 작업 실행 환경을 추가해야 합니다. 이 버전에는 매일 정시 자동 실행 기능이 없습니다.
- 무료 인스턴스는 성능이 작아 합성이 오래 걸리거나 중단될 수 있습니다. 1편을 만들어 본 뒤 운영 여부를 판단하세요.

API 키는 Render Environment에 저장하면 재시작 후에도 다시 주입됩니다. 사이트 입력란에 넣는 임시 설정과 다릅니다. Render가 관리하는 키는 화면에서 덮어쓰지 않습니다. Environment를 바꾼 후 재배포하세요. 키를 GitHub 파일에 넣지 마세요.

## YouTube 자동 업로드는 선택 사항

첫 시험에서는 직접 업로드하면 OAuth 설정이 필요 없습니다. 자동 업로드를 원할 때만 다음을 추가하세요.

1. Google Cloud에서 YouTube Data API v3 활성화, OAuth 동의화면 설정.
2. 웹 애플리케이션용 OAuth 클라이언트 생성.
3. 승인된 리디렉션 URI를 **발급된 Render 사이트주소/oauth/callback**으로 등록. 사이트 설정 화면에서도 정확한 값을 확인할 수 있습니다.
4. Render Environment에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` 입력 후 재배포.
5. 사이트에서 YouTube 채널 연결 → 완성 영상 확인 → 게시 승인.

OAuth 연결 토큰은 무료 서버의 임시 파일에 저장되어 재시작 때 다시 연결해야 할 수 있습니다. 이 토큰을 GitHub에 저장하지 마세요. 외부 영구 저장소를 연결하기 전에는 직접 업로드가 간단합니다. 이미 발급받은 refresh token이 있다면 운영자가 Render의 `YOUTUBE_REFRESH_TOKEN` 환경값으로 관리할 수 있습니다.

업로드는 기본 비공개, 아동용 아님, AI 생성 콘텐츠 포함으로 설정됩니다. 아동 대상 채널은 상태 설정 확장이 먼저 필요합니다. 미검증 API 프로젝트는 업로드가 비공개로 제한될 수 있습니다. 실제 업로드 결과가 불확실하면 중복 업로드를 막기 위해 자동으로 다시 올리지 않습니다.

## 접속·운영

- 기본 주소는 Render가 주입하는 `RENDER_EXTERNAL_URL`입니다.
- 개인 도메인을 연결하면 Render의 `APP_URL` 환경값에 `https://자신의주소`를 저장하고 Google OAuth 리디렉션 URI도 갱신하세요.
- 모든 화면·제작 API·영상 다운로드에 접속 비밀번호가 적용됩니다. `/healthz`만 상태 확인용으로 공개됩니다.
- API 키가 있어야 유료 제작을 시작하며, 제작 버튼을 한 번 누르면 한 편만 생성합니다. 서버 실행 중 중복 요청을 잠그지만, 서버 재시작 뒤 이전 원격 작업까지 추적하는 영구 작업 큐는 없습니다.
- 원본 장면 음성은 제거하고 별도 생성한 한국어 내레이션으로 합성합니다. 자막은 장면 단위이며 단어별 타이밍 자막은 아닙니다.
- 인터넷 단절이나 실패 후 자동 유료 재시도를 하지 않습니다.

## 검증과 한계

기본 검사, 비밀번호 접근 차단, Host·Origin 검사, API 키 응답 숨김을 확인했습니다. 제공사 응답을 테스트 데이터로 대체하고 실제 FFmpeg로 4장면·음성·자막 MP4 합성을 확인했습니다. Render 실제 배포, 무료 서버 부하, 유료 생성, YouTube 업로드, 브라우저 화면 자동 검증은 아직 수행하지 않았습니다.
