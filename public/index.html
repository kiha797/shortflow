채널 · API 설정

처음 한 번 채널의 범위를 정하면, 소재는 매번 자동으로 고릅니다.

이 파일은 화면 체험용입니다. API 연결은 압축 파일의 START-WINDOWS.cmd로 서버를 실행한 뒤 설정하세요.

01 채널의 방향

매번 소재를 직접 입력할 필요가 없습니다.

공식 인기 목록의 제목만 참고합니다. 영상·대본은 가져오지 않습니다.
이 기능은 동일 Google 프로젝트의 YouTube Data API 활성화가 필요합니다.

02 AI 제작 연결

소재·대본·음성은 Gemini, 장면은 Veo로 생성합니다.

Render에서는 Environment의 GEMINI_API_KEY에 키를 저장하세요. 아래 입력란에 저장한 키는 재시작 때 사라질 수 있습니다. ChatGPT 구독과 API 이용료는 별도입니다.
FFmpeg · FFprobe 연결을 확인합니다.

03 예상 비용

제공사의 현재 요금을 확인해 원화 단가를 입력하세요.

1편 = 8초 × 4장면 + 대본·음성 예상 합계. 실제 청구액은 제공사와 환율에 따라 달라집니다. 재생성은 추가 비용이 발생하며, 실패한 요청도 과금될 수 있습니다.

04 YouTube 연결

완성본 확인 → 공개 범위 선택 → 게시 승인 순서입니다.

Google Cloud에서 웹 애플리케이션용 OAuth 생성.
승인된 리디렉션 URI: 사이트주소/oauth/callback

Render에서 첫 영상 만들기

체험은 바로, 실제 영상은 API 연결 후 시작하세요.

  1. 먼저 체험 모드로 흐름 확인
    체험은 정해진 예시로 화면과 대본 구성을 보여줍니다. AI 영상 파일을 생성하거나 YouTube에 올리지 않습니다.
  2. Render에 배포
    GitHub 저장소를 연결하고 New → Blueprint에서 render.yaml을 적용하세요. 무료 플랜으로 설정되어 있으며 Node.js·FFmpeg·한글 글꼴이 자동 설치됩니다. 접속 아이디는 admin, 비밀번호는 배포 때 입력한 ACCESS_PASSWORD입니다.
  3. Gemini API 키와 단가 입력
    Google AI Studio에서 결제와 Veo 모델 사용 권한을 확인한 API 키를 만듭니다. 채널 분야와 제공사 단가를 설정하면 실제 제작 버튼을 사용할 수 있습니다.
  4. 영상 만들기
    소재 5개 발굴 → 중복 제거·1개 선정 → 대본·4장면 → AI 장면·음성 → 자막·합성. 30~45초, 세로 720×1280 MP4를 만듭니다. 제작 중에는 페이지를 열어 두세요. 무료 서버는 중단·재시작될 수 있어 결과는 즉시 다운로드하세요.
  5. 확인 후 게시 승인
    Google Cloud에서 YouTube Data API와 OAuth 동의화면을 설정합니다. 테스트 상태라면 내 Google 계정을 테스트 사용자에 추가합니다. 채널을 연결한 후 완성 영상을 확인하고 공개 범위를 선택해 승인합니다. 실제 같은 파일의 중복 업로드는 차단합니다.

미검증 YouTube API 프로젝트는 업로드가 비공개로 제한될 수 있습니다. 생성된 설명의 사실관계와 과학적 표현은 게시 전에 확인하세요. 자동 생성만으로 수익창출이 보장되지는 않습니다.
